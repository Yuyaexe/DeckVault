# Backup e restauração

## Criar um backup

1. Abra **Configurações**.
2. Encontre a área **Backup**.
3. Clique em baixar.
4. Guarde o arquivo JSON em uma pasta segura.

Faça isso antes de reinstalar o programa, trocar de computador ou limpar dados do navegador.

## Restaurar

1. Abra **Configurações**.
2. Encontre a área de restauração.
3. Selecione o arquivo JSON do backup.
4. Confirme e aguarde a conclusão.
5. Confira as coleções e quantidades.

## Cópia local organizada

A pasta `dados-locais/backups` guarda cópias manuais relacionadas ao projeto. Ela não substitui um backup em outro disco ou serviço de armazenamento.

## Regra simples

Mantenha pelo menos duas cópias: uma no computador e outra fora da pasta do DeckVault.
