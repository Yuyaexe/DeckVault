# Configurar compras do CardTrader

1. Instale a versão 0.2.10 e abra o DeckVault.
2. Abra Configurações → CardTrader.
3. Cole seu token da API e clique em Salvar token.
4. Abra Compras e clique em Atualizar.

O token fica salvo neste PC, em texto simples, fora da pasta do projeto. Ele não faz parte do instalador ou do backup da coleção. Para apagá-lo, use Remover token.
