# Usar a coleção

## Adicionar cartas

1. Abra **Coleção**.
2. Use a busca ou o botão de adicionar.
3. Procure o nome da carta.
4. Escolha a edição correta.
5. Confirme a quantidade.

## Visualizar

Use os botões de visualização para alternar entre grade, fichário, tabela e modo compacto.

## Organizar

- Use filtros para encontrar cartas.
- No fichário, arraste as cartas para mudar a ordem.
- Crie coleções separadas quando quiser manter grupos diferentes.

## Anime Collection

Abra **Anime Collection**, escolha uma série e depois um personagem. Adicione as cartas do personagem da mesma forma que na coleção principal.
