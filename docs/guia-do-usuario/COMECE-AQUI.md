# Comece aqui

## Abrir o DeckVault no Windows

1. Abra a pasta `releases/0.2.11`.
2. Execute `DeckVault-Setup-0.2.11.exe`.
3. Conclua a instalação.
4. Abra **DeckVault** pelo menu Iniciar ou pelo atalho criado.

Se o Windows mostrar um aviso, confirme apenas se o nome do arquivo é `DeckVault-Setup-0.2.11.exe` e se ele veio desta pasta do projeto.

## Abrir no navegador local

1. Clique duas vezes em `DeckVault.bat` na pasta principal.
2. Aguarde o navegador abrir.
3. Não feche a janela preta enquanto estiver usando o DeckVault.
4. Quando terminar, volte à janela preta e pressione uma tecla.

## Primeira tarefa recomendada

1. Abra **Coleção**.
2. Adicione ou importe algumas cartas.
3. Abra **Configurações**.
4. Baixe um backup.

O programa salva localmente. Faça backups com frequência.
